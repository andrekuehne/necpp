Detailed Description

A stateful, deck-free native solver above nec_context.

The class owns one context and one retained interaction-matrix factorization. Configuration mutations invalidate the factorization; voltage and far-field changes do not.

◆ set_lattice()

void nec_stateful_model::set_lattice ( const nec_lattice_definition & lattice)

Make the geometry the unit cell of an infinite periodic array.

Port impedances then become scan impedances. Scan phases reset to zero (broadside). Requires completed geometry without symmetry, in free space. Far-field, embedded-field and isolated-element calls are refused while a lattice is set.
