Detailed Description

Immutable input contract for one final geometry symmetry operation.

Reflection uses reflection_plane_mask and requires rotational_order == 1. Rotation uses rotational_order >= 2 about global Z and requires a zero reflection_plane_mask. tag_increment is a positive offset per copy block.
